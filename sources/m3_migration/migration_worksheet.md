# 단일 에이전트 활용한 업무를 서브에이전트로 분리하여 멀티 에이전트를 구축할 수 있도록 에이전트 마이그레이션 지침서 작성 

예시 1 : 빌드 리뷰(Galaxy 앱 개발팀)
- AS-IS : 단말 프롬프트로 이 어플리케이션 소스 코드에 대해서 리뷰 코멘트를 써줘라고 명령을 내리고 Try&Fail로 수정을 해옴
- TO-BE :
 1. Analyer Agent -- 지침서를 읽고 소스코드의 변경 범위를 파악하는 에이전트
 2. Risk Agent -- 보안/성능/호환성 이슈와 위험을 탐지하는 에이전트
 3. Reviewer Agent -- 심각도 분류 및 내용 코멘트 작성 에이전트
 4. Notification Agent -- Slack/Jira에 티켓 생성하는 에이전트


TASK 1 - 사내에서 검출된 이슈를 사외 시스템에 등록
- AS-IS : 사내 검증에서 검출, 사내 시스템에 등록된 이슈에 대해 단일 에이전트로 기본적인 로그를 분석하고, 당사에서 처리할 내용이 아닌 경우 타사 이슈 트래커 시스템에 등록
- TO-BE : 
1. Problem Manager Agent -- 사내 시스템에 등록된 이슈를 파악하고 이슈 번호에 따른 첨부 파일과 이슈 명세를 파악하는 에이전트
2. Precondition Check Agent -- 로그 기본 분석, 필수 패키지의 버전이 낮지는 않은지, 필요 system property가 제대로 세팅되어 있는 지 분석하는 에이전트 
3. Log Analysis Agent -- 로그와 명세로 이슈 내용 분석, 유관 패키지를 산출하는 에이전트
4. Comment Agent -- 분석 결과 코멘트 작성 에이전트
5. Reporter Agent -- 외부 이슈 트래커 시스템에 이슈 내용과 관련 첨부 파일을 등록하는 에이전트


TASK 2 - 자주검증에서 확인한 이슈를 사외 시스템에 등록
- AS-IS : 테스트 도중 확인한 이슈에 대해 단일 에이전트로 기본적인 로그를 분석하고, 당사에서 처리할 내용이 아닌 경우 타사 이슈 트래커 시스템에 등록
- TO-BE : 
1. Logging Agent -- 유관 로그들을 단말에서 추출하는 에이전트
2. Precondition Check Agent -- 로그 기본 분석, 필수 패키지의 버전이 낮지는 않은지, 필요 system property가 제대로 세팅되어 있는 지 분석하는 에이전트  
3. Content writer Agent -- 로그에서 테스트 시 사용된 유관 패키지 버전들을 확인해서 기술하고, 첨부 비디오 또는 문제 설명 분석을 통해 이슈 내용을 기술하는 에이전트
4. Reporter Agent -- 외부 이슈 트래커 시스템에 이슈 내용과 관련 첨부 파일을 등록하는 에이전트
